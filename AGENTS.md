# Two agents work in this repo (Claude Code and Cursor)

Both commit to `main`, often within minutes of each other, mostly under `public/wa` (the Whisky Advocate site) and `src/`. Rules so neither overwrites the other's work:

- Before editing, `git fetch origin main` and build on main's version of every file you touch. Never copy a whole folder or a whole stylesheet from a scratch directory over `public/wa`; apply your change to the file as it stands on main.
- Append new CSS in its own commented block rather than rewriting the file. Before pushing, check the diff for removed lines you did not mean to remove (`git diff origin/main... -- public/wa/site.css | grep '^-'`).
- Keep commits small and describe what they change in one line, so the other agent can read the history and keep your work when touching the same file.
- `public/wa/gen` is scratch; do not commit it.
- Data files (`stories.json`, `stories-archive.json`, `articles/*.json`, `ratings.json`, `top20.json`) are regenerated by scripts; regenerate from the current export rather than restoring an older copy.
- Never run two CMS maintenance jobs (`cms-maintenance.yml`) at once; four at once exhausted the database's connection pool and took the site down.

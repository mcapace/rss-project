# RSS Project

A modern RSS feed reader, aggregator, and parser built with Next.js 16 (App Router), TypeScript, and Tailwind CSS.

## Features

- **RSS & Atom Feed Parser**: Server-side feed parsing with caching and error handling.
- **Interactive Feed Reader**: Search, filter, and preview articles directly within the dashboard.
- **Preset Feeds**: Instant access to popular news, tech, and science feeds.
- **Custom URL Support**: Fetch and inspect any valid RSS or Atom XML feed.
- **Responsive Dark Theme UI**: Clean modern design built with Tailwind CSS.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org) (App Router)
- **Styling**: Tailwind CSS
- **RSS Parser**: `rss-parser`
- **Icons**: `lucide-react`
- **Deployment**: [Vercel](https://vercel.com)

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Build & Test

```bash
npm run build
```

Swapping them in Ad Manager
  1. Download a campaign's zips below (one zip per size, or all sizes at once).
  2. In the order Whisky Advocate House ads, line item LIVE WAO Ads: Add creative → HTML5 → upload the size's zip. Ad Manager reads its size from the bundle.
  3. Ad Manager finds the clickTag; paste the campaign's link (shown under each campaign) as its click-through URL.
  4. Deactivate the old creative it replaces. Retire the three marked Retire above outright.
  5. Static JPG backups at the exact pixel size are there for any slot or partner that takes images only.

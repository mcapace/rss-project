## 3. The new creatives

Each campaign comes in seven sizes. Two ways to put them in Ad Manager:

**A. HTML5 upload (recommended).** In the line item, *Add creative* → *HTML5*, upload the size's zip (`WA-<campaign>-<size>.zip` from `WA-house-ads.zip`, or the gallery's download buttons), and set the `clickTag` click-through to the URL below. Each zip is under 950 KB and 7 files or fewer.

**B. Hosted tag.** A *Custom* (or third-party) creative of the same size whose code is an iframe on the hosted bundle. The ad reads its click URL from the `clickTag` query parameter, so Ad Manager counts the click and then sends the reader to the landing page:

```html
<iframe src="https://rss-project-ten.vercel.app/wa/house-ads/notes/300x250/index.html?clickTag=%%CLICK_URL_ESC%%https%3A%2F%2Fwww.winespectator.com%2Fnewsletter%2Fwhiskyadvocate" width="300" height="250" frameborder="0" scrolling="no" style="border:0"></iframe>
```

Change the campaign, the size (in the path and in width/height) and the URL-encoded landing page for each creative. The hosted files are on the concept site's Vercel domain; move them to a company domain before relying on option B long term.
